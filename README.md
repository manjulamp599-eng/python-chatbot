# AI Chatbot

A simple rule-based AI chatbot developed using Python.  
This project is designed for beginners to understand the basic concepts of chatbot development and Python programming.

## About the Project

This chatbot interacts with users through the command line. It accepts questions from the user and provides predefined responses based on keywords and questions.

The chatbot does not use external AI libraries or APIs. It uses simple Python conditions such as `if`, `elif`, and `else`.

## Features

- Simple user-friendly conversation
- Greeting responses
- AI information
- Python information
- Machine Learning information
- Programming information
- Computer information
- Internet information
- Study suggestions
- Exam preparation suggestions
- College information
- Help command
- Goodbye response
- Unknown-question handling
